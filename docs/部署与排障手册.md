# 部署与排障手册

## 一、架构总览

```
客户端 → dnsmasq(53) → clash-rs DNS(1053, fake-ip)
  ↓                                ↓
国内域名(fake-ip-filter)    国外域名 → fake-ip 198.18.x.x
  ↓ 真实解析                    ↓
iptables cn_ip 直连          iptables REDIRECT 7892 → clash → 代理节点
  ↓ (不过 clash)               ↓
直连(快/稳)                  AUTO 组 url-test 选最快节点
```

## 二、关键配置项速查

### 1. AUTO 组（节点选择）
```yaml
- name: AUTO
  type: url-test
  url: http://cp.cloudflare.com/generate_204   # 测速用连通性检测地址
  interval: 600                                 # 10 分钟测速一次
  tolerance: 100                                # 当前节点比最快慢 100ms 内不切换
  timeout: 5
```

### 2. fake-ip-filter（国内域名直连）
- 列表里的域名**真实解析**（不返回 fake-ip），命中 iptables cn_ip → 直连
- 本配置含 1022 条：`+.cn` 全量 + 大厂 CDN（字节/腾讯/阿里/百度/B站/美团等）
- 新遇到国内站卡 → 加一行 `- '+.域名'` 重载（注意：改动用 `init.d restart`，**禁止 PUT 热重载**）

### 3. 内存保护
| 项 | 值 |
|----|-----|
| vm.min_free_kbytes | 8192 |
| clash 内存软限 | 34MB（超过自动清理连接）|
| OOM 保护 | clash/watchdog/netifd/dnsmasq = -1000 |

## 三、日志怎么看

| 日志 | 内容 |
|------|------|
| /var/log/clash-watchdog.log | watchdog 心跳 + 崩溃记录（`not running` 频率）|
| /var/log/clash-rs.log | clash 本体错误（抓 `Address in use`=热重载事故）|
| /var/log/tune-tolerance.log | 降级/切换历史（每条带延迟「308->191ms」）|
| /var/log/fix-nodes.log | 节点 IP 修复记录 |
| /var/log/clash-exit.log | 退出码记录（137=OOM/139=段错误/143=终止）|

## 四、常见问题

### Q1: 节点切换太频繁
- 看 `tune-tolerance.log` 切换记录，若大量"小差切换"(100ms 内) → 调大 tolerance
- 若节点延迟暴涨触发 → 是节点问题，考虑换机场

### Q2: 某天突然没网
1. `netstat -ulnp|grep 1053` — 1053 是否 clash 监听
2. `uci get dhcp.@dnsmasq[0].server` — 是否被重置为 119/223
3. `tail -30 /var/log/clash-watchdog.log` — 崩溃前发生了什么

### Q3: 核心开着但大陆站卡
- 确认域名在 fake-ip-filter：`nslookup 域名 127.0.0.1`，返回真实 IP 且 `curl 域名` 快
- 若返回 198.18.x.x → 域名不在列表 → 加入 fake-ip-filter

### Q4: 修改配置后怎么生效
- **tolerance/interval 等 AUTO 参数**：可用 `PATCH /configs` 热改（零重启）或 `cc autogroup`
- **fake-ip-filter/规则/proxy**：改 config.yaml 后 `init.d restart`（**禁用 PUT /configs 热重载**，会导致 1053 冲突没网）

## 五、备份恢复
```bash
# 备份
tar czf /tmp/cfg.bak.tar.gz /etc/clash-rs/config.yaml /etc/clash-rs/tolerance.conf /etc/init.d/clash-rs /usr/bin/*.sh
# 恢复
tar xzf /tmp/cfg.bak.tar.gz -C /
```
